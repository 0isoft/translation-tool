Translation Assistant

This is the Microsoft Word add-in which takes in track changes in a source cell, and translates/updates the changes in the corresponding neighboring cells, for the Tab files.

Download Word add-in manifest

Install in Word

  1. Download the manifest using the button above.
  2. In Word, open Home → Add-ins → More Add-ins.
  3. Open My Add-ins, choose Upload, and select the manifest. If this is not available, try this instead:
      Create a folder and name it something like "office addons", somehwere on your computer
      Then put the manifest file in that folder
      Go to Word: File → Options → Trust Center → Trust Center Settings → Trusted Add-in Catalogs
      Select the folder containing the manifest
      Restart Word
  4. Open Translation Assistant from Word.

After installation, the add-in should connect to an online server I've set up. If the Upload option is unavailable, it's likely that Datos has disabled custom add-ins for Sharepoint apps (like MS Word), so we'll have to check with them.

Document processing, how does it work?

Only affected source paragraphs(+tracked changes to them), and the three corresponding language cells are sent to Claude. The complete document is not uploaded.
